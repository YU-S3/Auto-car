# Soberup 2026

这是一个固化的智能车控制工程开源归档，包含两个可独立使用的完整版本。

| 分支 | 内容 | 适用场景 |
| --- | --- | --- |
| `main` | N30pro 固化版 | 默认版本；以视觉循迹、岔路状态和姿态/里程反馈为主体 |
| `inav` | 惯导固化版 | 路径、二维定位、重定位和道路状态方案 |

## 切换版本

```bash
git clone <仓库地址>
git switch main       # N30pro
git switch inav       # 惯导版
```

每个分支都包含完整的工程定义、`code/`、`user/` 和编译必需的 `libraries/`。请勿在两个分支之间混合复制源文件。

## 构建

1. 使用 AURIX Development Studio 导入根目录的 `.project`。
2. 确认使用与工程匹配的 Tasking 工具链和 TC264D 目标配置。
3. 选择工程的构建配置，编译后按实际硬件环境烧录。

本仓库不提供预编译固件；相机、电机、编码器和 IMU 的安装与标定参数需与实际车辆匹配。
