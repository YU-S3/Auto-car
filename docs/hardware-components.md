# 疯狂电路视觉智能车：硬件型号与保守计算资源

2026-11-14规则补充：全国第21届允许指定ST IMU，本车RB所列LSM6DSRTR属于器件范围；全国自制电路、PCB标识与制作要求需独立核查，现有商业学习主板和成品驱动板不能直接认定全国参赛合规。文杰杯PPT推荐套件的校赛范围另行保留。详见[全国规则基线](research/2026-11-14-national21-rule-baseline.md)。本表记录现有硬件，不因规则核对而擅自更改型号或240KB资源预算。

硬件版本：用户确认的v0.3。文档日期：2026-11-13。用途：后续视觉、规划、控制及C语言算法实现的统一参考。**主控SRAM规格固定为240KB，不将工程预算或某份链接模板的分区数值改写为芯片总容量。** 本文内存预算统一按1KB=1024B计算。

## 2. 保守内存预算

算法实现按以下上限设计，而不是用满240KB。各项是**项目预留预算，不是测得的可用量**；保留给系统及余量的空间不可再分配给额外算法数组。最终还需满足每个实际链接区的布局约束。

| 项目预算桶 | 上限/预留 | 说明 |
| --- | ---: | --- |
| 视觉＋规划＋控制的算法数据总预算 | **≤96KB＝98,304B** | 包含采集帧、快照、二值图、点集、规划状态及控制状态；驱动已有图像也计入，不重复计算 |
| SDK、启动、CSA、栈、中断、通信等预留 | **96KB＝98,304B** | 预留不是可随意申请的堆；.map及栈水位决定是否足够 |
| 不分配的容量保护余量 | **48KB＝49,152B** | 首版不消耗，不据此承诺特定地址区还有48KB数据堆 |
| 芯片总SRAM规格 | **240KB＝245,760B** | 96＋96＋48＝240；分区布局另行检查，不改变器件总容量 |

96KB算法桶的初始拆分：

| 数据 | 字节数 |
| --- | ---: |
| 原始采集帧188×120 | 22,560 |
| 只读快照或第二灰度帧 | 22,560 |
| 8位二值图 | 22,560 |
| 边界/中心点等工作区预算 | 8,192 |
| 阈值、直方图等预算 | 4,096 |
| 路线、事件、控制状态预算 | 4,096 |
| 已计划合计 | **84,064** |
| 算法桶内尚未分配 | **14,240** |

后四项是设计上限，具体数据结构定义后逐数组核算。超过上限应调整算法或数据表示，不能默默占用系统预留。

- 不默认新增64,800B IPS完整RGB565帧缓存，采用驱动行缓冲/局部刷新。
- 不保留两张全图float逆透视查表；188×120×4B×2＝180,480B，超过算法预算。
- 不进行依赖无界堆内存的图搜索；路线容量、队列和迭代次数均设置上限。
- 大图使用静态内存和明确所有权；不能只看总量，也不能把所有图都放入同一局部区。
- 单核首版不等于所有数组只能放CPU0局部区；具体放置要按ADS链接配置、DMA访问和.map核对。

## 3. 保守时间预算

首版只让一个CPU执行应用算法，不把双核算力相加承诺吞吐。按最高200MHz平台设计，实际主频必须由工程确认；以下均为待上板验证的目标。

| 工作 | 初始目标 | 预算约束 |
| --- | --- | --- |
| 视觉＋决策 | 30Hz | 每次≤15ms，约占单核45%；处理最新完整帧，可主动跳帧 |
| 轮速闭环 | 200Hz | 单次目标≤0.5ms；与IMU/必要中断合计预留单核15%以内 |
| 屏幕和调试 | 屏幕5Hz、日志限流 | 低优先级、局部刷新；目标占用≤5%，不得阻塞控制截止期 |
| 单核保护余量 | ≥35% | 按实际执行时间统计；不依赖CPU1补足首版时序 |

若测得超预算，先减显示负载、ROI、分辨率或车速，再考虑分核。摄像头配置50FPS、商品最高FPS、视觉目标30Hz和实际端到端延迟四者分别记录。

## 4. 软件约束与待标定项

实现使用C99/C11兼容子集；PC和TC264共享同一份算法源码；Python/OpenCV只用于回放、标注和对照。核心算法不包含逐飞SDK、寄存器和绘屏接口。首版采用传统视觉＋状态机＋差速闭环，暂不增加神经网络或RTOS依赖。

以下参数不能从开源车模照搬：GPIO/外设映射、左右正方向、有效count/rev、齿比、轮径/轮距、IMU轴向和零偏、采样周期、PWM频率/极性/制动、曝光/增益、相机高度/俯角、线宽尺度、补线阈值和PID增益。

逐飞官方源码与接口依据见[硬件开发核验](hardware-profile.md)。已下载源码的版本及使用边界见[Soberup基线说明](../soberup/README.md)。
